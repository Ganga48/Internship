Tableau Sales & Profitability Dashboard
This project uses the Sample Superstore dataset in Tableau Public to analyze sales, profit, shipping, and product performance. The dashboard helps management quickly understand key business trends through interactive charts.

Key Insights:

Office Supplies had the lowest revenue.

The West Region was the most profitable.

Standard Class shipping generated the highest sales.

Top sub-categories driving business were identified.

A scatter plot highlighted sub-categories with both high sales and high profit.

Tools Used: Tableau Public, Sample Superstore Dataset, GitHub
