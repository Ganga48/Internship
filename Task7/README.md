Internship task7

This project shows how to create a basic SQL database with two tables: customers and orders. It includes sample data and demonstrates how to use INNER JOIN and LEFT JOIN to combine information from both tables.

INNER JOIN: Displays only customers who have matching orders.

LEFT JOIN: Displays all customers, even if they don’t have any orders (shows NULL for missing matches).

The sample data also includes an order linked to a non‑existent customer (CustomerID = 4), which helps illustrate how joins handle unmatched records.
